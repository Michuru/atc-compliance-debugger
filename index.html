BeyondATC Compliance Debugger

Load a Player.log and see every ATC instruction paired with what the aircraft actually did — heading, altitude, and speed compliance, checked automatically. Built as an elimination step before filing bugs against BeyondATC itself: if this tool shows the pilot correctly following every instruction and BeyondATC's own ATC still misbehaved, that's evidence the bug is in BeyondATC, not the pilot.

Open the Tool atc-compliance-debugger.html — runs entirely in your browser, nothing uploaded

Drag and drop a Player.log file onto the page once it loads, or use the file picker.
